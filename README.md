Projeto desenvolvido em Excel como parte do curso da DIO
Este projeto foi desenvolvido em Microsoft Excel como parte de um desafio de estudos da plataforma DIO, com o objetivo de organizar dados de assinaturas do Xbox Game Pass e apresentar informações relevantes por meio de um dashboard.
A solução utiliza uma base de dados de assinantes, tabelas de apoio e cálculos consolidados para estruturar informações relacionadas aos planos, valores das assinaturas, renovações e aquisição de serviços adicionais.
O projeto tem como foco a aplicação prática dos recursos do Excel na organização, análise e visualização de dados.
O objetivo é desenvolver um dashboard que facilite a visualização e a análise de informações relacionadas às assinaturas do Xbox Game Pass, permitindo compreender melhor a composição dos dados e os valores associados aos serviços contratados.
Entre os objetivos do projeto estão: organizar os dados dos assinantes; estruturar informações sobre os planos disponíveis; analisar os valores das assinaturas; identificar informações relacionadas à renovação automática; consolidar dados sobre os adicionais EA Play Season Pass e Minecraft Season Pass; apresentar informações de forma visual e organizada.
O projeto contempla informações relacionadas a diferentes aspectos das assinaturas: Planos: identificação do plano contratado pelo assinante. Valores: informações sobre os preços das assinaturas e dos serviços adicionais. Renovação automática: classificação dos registros conforme a indicação de renovação. Serviços adicionais: informações relacionadas ao EA Play Season Pass e ao Minecraft Season Pass. Cupons: registro dos valores de cupons associados às assinaturas. Essas dimensões ajudam a estruturar uma visão geral dos dados disponíveis na base.
O projeto foi desenvolvido no Microsoft Excel, com utilização dos seguintes recursos: organização e estruturação de bases de dados; tabelas de resumo; tabelas dinâmicas; funções de recuperação de dados de tabelas dinâmicas; consolidação de valores; organização de informações por categorias; formatação de dados; lementos visuais para composição do dashboard; padronização de cores e identidade visual.
A construção deste projeto permitiu praticar conhecimentos relacionados à análise e à apresentação de dados no Excel, especialmente: organização de bases de dados; estruturação de informações para análise; utilização de tabelas dinâmicas; consolidação de valores; organização de indicadores e categorias; construção de dashboards; padronização visual de relatórios; transformação de dados estruturados em informações para análise. O projeto reforça a importância de organizar corretamente os dados antes de construir visualizações e apresentar resultados.
Este projeto possui finalidade educacional e foi desenvolvido como parte dos estudos na DIO.
Os dados utilizados são tratados como dados de demonstração para fins de aprendizado. As informações e os resultados apresentados dependem da base disponibilizada e da estrutura de cálculo da planilha.
